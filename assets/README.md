# assets/

Calle Sol -brändin mediatiedostot. Pidä tiedostot oikeissa alikansioissa ja
brändi-identiteetissä (ks. `../CLAUDE.md`).

```
assets/
├── logos/      # Logot ja wordmarkit  → SVG
├── graphics/   # Kuvitukset, sivellinmotiivit, ✦-aksentit, kaakelit → SVG
└── images/     # Valokuvat (filmikuva, kynttilänvalo, ruoka & viini) → JPG
```

## Nimeämiskäytäntö

Käytä pieniä kirjaimia ja väliviivoja:

- `logos/calle-sol-wordmark.svg`
- `logos/calle-sol-mark.svg`
- `graphics/tile-pattern.svg`
- `graphics/sparkle.svg`
- `images/hero-candlelight.jpg`
- `images/tapas-table.jpg`

## Käyttö HTML:ssä

```html
<img src="assets/logos/calle-sol-wordmark.svg" alt="Calle Sol" />
<img src="assets/images/hero-candlelight.jpg" alt="Pöytä kynttilänvalossa" />
```
